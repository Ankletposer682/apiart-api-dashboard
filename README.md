## 🚀 Setting up your first dashboard

Once you install the program, follow these steps to connect your data:

1. Open the APIArt application from your desktop icon.
2. Click the Add Source button.
3. Paste the URL of your JSON REST API into the text field.
4. Click the Test Connection button to verify the link.
5. Select the fields you want to track from the list.
6. Choose a visual style like a line chart or a bar graph.
7. Save your settings.
8. View your live dashboard.

## 🛠️ Managing your dashboard

The interface allows you to manage multiple connections. Use the sidebar to switch between different data streams. You can edit the settings for any component by clicking the gear icon on the visual element. To remove a component, select it and press the delete key.

## 📝 Tips for success

* Name your dashboards clearly so you can find them later.
* Use the refresh button if the data seems to pause.
* Group related charts together to make your data easier to read.
* Check the status indicator at the top of the screen to confirm your API connection.
* Save your work often to avoid losing your layout changes.
